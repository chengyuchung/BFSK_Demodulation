## 2. 信号流向详解

### 上行链路（井下 → 地面）

```
MCU₁(井下) 
    │
    │ ① 产生 BFSK 调制信号（AD9833 输出正弦波，f0/f1）
    ↓
AD9833 驱动电路（OPA2333 预放）
    │
    │ ② 驱动磁环①原边线圈（交变电流）
    ↓
磁环① ────────【磁耦合穿透金属管道壁】───────── 磁环①
    │
    │ ③ 副边线圈感应出同频电压
    ↓
有线线缆（穿管双绞线，10-30m）
    │
    │ ④ 信号传输到管道出口
    ↓
磁环① 副边侧（井上侧/中继侧）
    │
    │ ⑤ 感应到信号
    ↓
MCU_relay(中继) TIM 输入捕获 / ADC 采样
    │
    │ ⑥ 接收数据帧 → 校验 CRC → 返回 ACK/NACK
    ↓
    ├── 数据有效 → 转发至上位机（UART → USB → PC）
    └── 数据无效 → NACK → 等待井下重传（最多3次）
```

### 下行链路（地面 → 井下）

```
PC (QT 上位机) 
    │
    │ ① 下发命令帧（查询/校时/休眠/唤醒）
    ↓
USB → UART → MCU_relay
    │
    │ ② MCU_relay 构造命令帧，驱动 AD9833 → f_cmd
    ↓
AD9833 → 磁环①原边（井上侧）
    │
    │ ③ 磁耦合 → 副边 → 有线线缆
    ↓
有线线缆 → 管道内 → 磁环①原边（井下侧）
    │
    │ ④ 井下侧副边感应
    ↓
MCU₁(井下) TIM 捕获 → 解调 → 执行命令
    │
    │ ⑤ 返回应答帧（确认/数据）
    ↓
同样的磁环① 通路传回井上
```

## 3. 关键参数修正（基于真实架构）

| 参数 | 修正后值 | 说明 |
|------|---------|------|
| 磁耦合距离 | **5-20mm** | 仅穿透金属壁，非远距离无线 |
| 线圈口径 | **几 cm 即可** | 穿管磁环尺寸，市售品 |
| 功放功率 | **几十 mW–500mW** | 磁环驱动功率需求极低 |
| 线圈 Q 值 | **30-100** | 普通铁氧体磁环即可 |
| 通信距离 | **有线 10-30m** | 真正的距离由有线承担 |
| 磁环选型 | **锰锌铁氧体（MnZn），EI/EE 型磁芯** | 适合 100k-1MHz |

## 4. 有线线缆特性分析

穿管双绞线在 100kHz-1MHz 下的特性：
- **集肤效应**：在 1MHz，铜的集肤深度约 66μm，普通 AWG22（0.64mm）线径在集肤深度内，交流阻抗增加
- **特性阻抗**：约 50-100Ω（与线距、介质相关）
- **衰减**：100kHz 下每 10m 约 0.5-1dB（可接受）
- **建议**：使用屏蔽双绞线（STP）减少外部干扰，或加粗线径（AWG18）降低电阻

## 5. 中继节点与上位机接口

```
MCU_relay                    上位机 QT
    │                             │
    │ <────── 业务数据帧 ──────>  │
    │ <────── 握手帧 ──────────>  │
    │ <────── 告警帧 ──────────>  │
    │ <────── 命令帧 ──────────>  │
    │ <────── ACK/NACK ────────>  │
    │                             │
    └── UART TX/RX (115200bps) ───┘
```

中继节点与上位机之间走 UART，中继节点内部 MCU_relay 直接与井下终端通过磁环+有线通信。
