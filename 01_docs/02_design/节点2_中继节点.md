# 中继节点设计规格

> 本文档详细定义中继节点的硬件、软件、状态机和功耗预算。
> 中继节点位于井下与井上之间，承担信号桥接、协议转换、扫频协调、数据汇聚等关键职责。

## 1. 功能职责

- **信号桥接**：连接井下磁环①和井上磁环②的双向磁耦合链路
- **协议转换**：井下 BFSK ↔ 井上 BFSK（可能不同频点）之间做帧级转发
- **扫频协调**：发起并协调井下-中继、井上-中继两段链路的自适应扫频选频
- **数据汇聚**：缓存井下上报的数据帧，统一转发至井上节点
- **链路管理**：ACK/NACK 应答、停等重传控制（最多 3 次）
- **命令转发**：将井下命令/校时/休眠等帧从井上转发至井下
- **低功耗管理**：电池供电，与井下同步进入休眠

### 信号链

#### 井下侧（磁环①）

```
下行发送（→井下）:
MCU ── SPI1 ──→ AD9833 #1 ──→ OPA2333 ──→ OPA549 ──→ 磁环①原边
                                                              ↓
                                                         磁耦合穿透管壁
                                                              ↓
                                                         磁环①副边 ──→ 井下

上行接收（←井下）:
井下 ──→ 磁环①副边 ──→ AD8421 LNA ──→ 带通滤波 ──→ ADC1 / TIM1 捕获 ──→ MCU
```

#### 井上侧（磁环②）

```
上行发送（→井上）:
MCU ── SPI2 ──→ AD9833 #2 ──→ OPA2333 ──→ OPA549 ──→ 磁环②原边
                                                              ↓
                                                         磁耦合穿透（井上端隔离）
                                                              ↓
                                                         磁环②副边 ──→ 井上

下行接收（←井上）:
井上 ──→ 磁环②副边 ──→ AD8421 LNA ──→ 带通滤波 ──→ ADC2 / TIM2 捕获 ──→ MCU
```

### 电源

- 主电源：18650 × 2 串联（7.4V 标称）
- 3.3V / 5V 供电：TPS5430 双路输出
- CR2032 备份电池：RTC 保持

## 5. 关键算法：双侧扫频协调

中继节点是扫频选频的"主导者"。具体流程：

### 井下侧扫频（Step A）

```
1. 中继生成扫频命令帧（频点列表 [100k, 150k, ..., 1000k]）
2. 中继向井下发送"准备扫频"命令
3. 井下进入接收准备状态（启动 ADC + DMA 连续采样）
4. 中继依次在每个频点发送单频载波（持续 100ms）
5. 中继切换频点，井下做 FFT 分析，记录幅值
6. 井下发送"频点候选"帧（上报所有频点幅值）
7. 中继根据井下上报数据，结合自己的接收强度，确定井下侧 f0/f1
8. 中继向井下下发"频点确认"帧（f0/f1）
```

### 井上侧扫频（Step B）

类似井下侧流程，中继作为发送/接收方与井上节点交互。

### 频点对决策算法

```c
// freq_select.h
typedef struct {
    uint16_t freq_hz;      // 频率值
    int16_t  amplitude_db; // 信号幅值（dB）
} FreqCandidate;

void select_best_pair(FreqCandidate* candidates, uint8_t n,
                     uint16_t* f0_out, uint16_t* f1_out) {
    // Step 1: 找幅值最高的频点 → f1
    int max_idx = 0;
    for (int i = 1; i < n; i++) {
        if (candidates[i].amplitude_db > candidates[max_idx].amplitude_db) {
            max_idx = i;
        }
    }
    *f1_out = candidates[max_idx].freq_hz;

    // Step 2: 在剩余频点中找与 f1 差 ≥ 50kHz 的最优幅值 → f0
    int best_idx = -1;
    int best_amp = -1000;
    for (int i = 0; i < n; i++) {
        if (i == max_idx) continue;
        if (abs(candidates[i].freq_hz - *f1_out) < 50000) continue;
        if (candidates[i].amplitude_db > best_amp) {
            best_amp = candidates[i].amplitude_db;
            best_idx = i;
        }
    }
    *f0_out = candidates[best_idx].freq_hz;
}
```

## 6. 帧转发策略

### 上行（井下→中继→井上）

```
井下 → [BFSK @ 井下侧 f0/f1] → 中继
中继接收 → CRC 校验 → 解析帧类型
  ├─ 业务数据帧 → 加入上行发送队列
  ├─ 告警帧 → 立即置顶上行队列
  └─ 应答帧 → 不需要上行转发（井下 ACK 是给中继的）

中继 → [BFSK @ 井上侧 f0/f1] → 井上
```

### 下行（井上→中继→井下）

```
井上 → [BFSK @ 井上侧 f0/f1] → 中继
中继接收 → CRC 校验 → 解析帧类型
  ├─ 命令帧（针对井下）→ 加入下行发送队列
  ├─ 应答帧 → 转发至井下
  └─ 其他 → 丢弃

中继 → [BFSK @ 井下侧 f0/f1] → 井下
```

### 时分双工（TDD）时序

```
┌─────────┬──────────────┬──────────────┬─────────┐
│ 时隙 0  │    时隙 1     │    时隙 2     │  时隙 3  │
│ 中继→井上 │  井上→中继     │  中继→井下    │ 井下→中继 │
│ (上行)   │  (下行/ACK)   │  (下行/命令)   │  (上行)   │
│  50ms    │   20ms        │   50ms       │  50ms    │
└─────────┴──────────────┴──────────────┴─────────┘
总周期 170ms（可调）
```

## 7. 功耗预算

### 各模式电流估算

| 模式 | 电流 | 说明 |
|------|------|------|
| 深度休眠 | 5 μA | RTC + RAM |
| 待机 | 80 mA | MCU + 双侧 RTC |
| 双侧扫频（发送） | 400 mA | 双 AD9833 + 双 OPA549 |
| 单侧收发（井下侧） | 250 mA | - |
| 单侧收发（井上侧） | 250 mA | - |
| 全功率峰值（双侧同时收发） | 500 mA | - |

### 续航估算（与井下类似）

- 平均电流（1% 占空比）：~80 mA
- 18650 × 2 = 3000 mAh @ 7.4V
- 理论续航：**约 37 小时**

> **优化方向**：与井下类似，深度休眠时切断双侧 OPA549、AD8421 电源，仅保留 RTC。

## 8. 中继-井上链路特性

磁环②位于井上端，是井上节点机箱与中继节点之间的磁耦合气隙（5-20mm）。井上节点机箱可能放置在防爆箱/控制柜中，磁环②气隙在控制柜侧壁。
