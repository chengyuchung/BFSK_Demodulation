# 井下采集节点设计规格

> 本文档详细定义井下采集节点的硬件、软件、状态机和功耗预算。
> 井下节点是整个系统的最末端，负责油管内环境参数的实时采集，并通过磁环与中继节点进行 BFSK 通信。
> 同时作为链路末梢，兼具数据转发职责（将中继转发的命令/数据透传至井下底节传感器）。

## 1. 功能职责

- **传感器数据采集**：采集油管内温度、压力和电池电压
  - 温度采集：DS18B20（单总线 1-Wire）
  - 压力采集：BMP280（I2C 接口）
  - 电池电压：分压电阻 + N-MOS 控制，由 ADC3 采样
- **BFSK 物理层通信**：通过磁环①与中继节点进行 BFSK 调制解调
- **链路管理**：ACK/NACK 应答、停等重传控制（最多 3 次）
- **扫频配合**：在接收扫频信号期间记录频点幅值，配合完成自适应选频
- **命令执行**：接收并执行来自井上经中继转发的下行命令（校时、查询、休眠/唤醒等）
- **低功耗管理**：电池供电，支持深度休眠与间歇唤醒

## 2. 硬件资源清单

### 主控最小系统

- STM32L476RET6（Cortex-M4 低功耗系列，适合电池供电）

### 外设分配

| 外设 | 分配 | 说明 |
|------|------|------|
| SPI1 | AD9833 | 磁环①驱动（BFSK 调制） |
| TIM1 | 输入捕获 | 解调（CH1 上升沿 + CH2 下降沿） |
| TIM2 | 系统时基 | 1ms tick，处理 ACK 超时、扫频窗口、软件计时 |
| TIM6 | ADC 触发 | 10kHz 固定采样率，触发 ADC |
| ADC1（多通道） | 磁环①采样 + 电池电压 | 扫频阶段采样磁环① + 偶发电池电压监测 |
| USART1 | 调试串口 | 115200bps |
| I2C1 | DS3231 RTC + BMP280 | 400kHz |
| GPIO (PA0) | DS18B20 单总线 | 温度传感器 1-Wire 接口 |

### GPIO 控制口分配

| GPIO | 用途 | 说明 |
|------|------|------|
| GPIO_继电器_CTRL | 继电器控制 | 切换上行/下行通路 |
| GPIO_PA_EN | 功放控制 | OPA549 使能 |
| GPIO_NMOS_BAT | N-MOS 控制（电压采集） | 低电平导通 |
| GPIO_ADC1_BAT | ADC 输入（电池分压） | 接 200kΩ/100kΩ 分压点 |
| GPIO_ADC1_MAG | ADC 输入（磁环①） | 接磁环①采样点 |
| GPIO_WKUP | 休眠唤醒 | 外部唤醒输入 / RTC 唤醒 |
| GPIO_LED | 状态指示灯 | 调试用 |
