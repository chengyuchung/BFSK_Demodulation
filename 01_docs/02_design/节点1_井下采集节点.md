# 井下采集节点设计规格

> 本文档详细定义井下采集终端的硬件、软件、状态机和功耗预算。

## 1. 功能职责

- 周期采集温度（PT100）和压力（Honeywell 26PC）数据
- 通过 AD9833 + 磁环① 与中继节点建立 BFSK 通信链路
- 接收中继下发的命令帧（查询/校时/休眠/唤醒）
- 上报业务数据帧、告警帧
- 自适应低功耗管理（深度休眠 → 定时唤醒）

## 2. 硬件资源清单

### 主控最小系统

| 资源 | 用途 |
|------|------|
| STM32F407VET6 | 主控 MCU |
| 外部晶振 8MHz | HSE，系统主时钟源 |
| 32.768kHz 晶振 | LSE，RTC 时钟源 |
| SWD 接口 | 调试 / 烧录 |

### 外设分配

| 外设 | 分配 | 说明 |
|------|------|------|
| SPI1 | AD9833 控制 | SCK/MOSI/NSS/CS |
| SPI2 (备用) | 扩展 | 预留 |
| TIM1 | 输入捕获（接收解调） | CH1 上升沿，CH2 下降沿 |
| TIM2 | PWM 输出（备用） | - |
| TIM3 | 系统时基 | 1ms tick |
| ADC1 + ADC2 | 扫频阶段 FFT 数据采集 | DMA 双通道交替采样 |
| ADC3 | 电池电压监测 | 单通道 |
| USART1 | 调试串口 | 115200bps |
| USART2 | 与中继节点有线直连（备用） | 调试接口 |
| USART3 (备用) | 扩展 | - |
| I2C1 | DS3231 RTC | 400kHz 快速模式 |
| I2C2 | MAX31865（PT100） | 400kHz |
| GPIO | 磁环使能、PA 使能、休眠控制 | 多路 |

### 信号链

```
[采集侧]                    [通信侧]
PT100 ── MAX31865 ──→ I2C2 ──→ MCU
26PC  ── INA128 ──→  ADC ──→ MCU (压力值)

MCU ── SPI1 ──→ AD9833 ──→ OPA2333 ──→ OPA549 ──→ 磁环①原边
                                                       ↓
                                                  磁耦合穿透金属壁
                                                       ↓
                                                  磁环①副边 ──→ 有线 ──→ 中继

磁环①副边（同上）── AD8421 LNA ──→ 带通滤波 ──→ ADC / TIM 捕获 ──→ MCU
```

### 电源

- 主电源：18650 × 2 串联（7.4V 标称，6.0–8.4V 范围）
- 3.3V 系统电源：TPS5430（7.4V→3.3V，效率 >90%）
- 5V 模拟电源：TPS5430（7.4V→5V，给 OPA549/INA128 供电）
- 备用纽扣电池 CR2032：RTC 保持
- 充电管理：TP4056（单节 18650，可选）

## 4. 节点状态机

### 主要状态

```
                        ┌──────────────┐
                        │   POWER_ON   │ 上电初始化
                        └──────┬───────┘
                               ↓
                        ┌──────────────┐
                        │   INIT_RTC   │ 同步 RTC
                        └──────┬───────┘
                               ↓
                  ┌────────────────────────┐
                  │  WAIT_SYNC_CMD         │ 等待中继下发握手
                  │  (超时 → 进入 SLEEP)   │
                  └────────────┬───────────┘
                               ↓ (收到握手)
                  ┌────────────────────────┐
                  │  SWEEP_FREQ            │ 扫频阶段
                  │  ·发送单频载波         │
                  │  ·等待应答频点对       │
                  └────────────┬───────────┘
                               ↓ (频点确定)
                  ┌────────────────────────┐
                  │  LINK_READY            │ 链路就绪
                  │  ·正常业务收发         │
                  └────────────┬───────────┘
                               ↓
                  ┌────────────────────────┐
                  │  SLEEP                 │ 低功耗休眠
                  │  ·RTC 定时唤醒         │
                  └────────────┬───────────┘
                               ↑ (唤醒)
                  ┌────────────┴───────────┐
                  │  DATA_COLLECT          │ 数据采集与上报
                  └────────────────────────┘
```

### 状态转换条件

| 当前状态 | 事件 | 下一状态 | 备注 |
|---------|------|---------|------|
| POWER_ON | 系统初始化完成 | INIT_RTC | - |
| INIT_RTC | RTC 同步完成 | WAIT_SYNC_CMD | 等待握手 |
| WAIT_SYNC_CMD | 收到握手帧 | SWEEP_FREQ | - |
| WAIT_SYNC_CMD | 超时（>30s） | SLEEP | 节能 |
| SWEEP_FREQ | 频点确定 | LINK_READY | - |
| SWEEP_FREQ | 扫频失败 | SLEEP | 重试 |
| LINK_READY | 收到休眠命令 | SLEEP | - |
| LINK_READY | 收到数据查询 | DATA_COLLECT | - |
| LINK_READY | 收到校时命令 | INIT_RTC | 重新同步 |
| DATA_COLLECT | 上报完成 | LINK_READY | - |
| SLEEP | RTC 定时唤醒 | DATA_COLLECT | 周期唤醒 |

## 5. 功耗预算

### 各模式电流估算

| 模式 | 电流 | 说明 |
|------|------|------|
| 深度休眠 | 5 μA | RTC + RAM 保持 |
| 待机（无通信） | 50 mA | MCU + 传感器待命 |
| 扫频（发射） | 200 mA | AD9833 + OPA549 + 磁环 |
| 数据接收 | 80 mA | AD8421 + ADC + MCU 解调 |
| 数据发射 | 250 mA | AD9833 + OPA549 满功率 |
| 全功率峰值 | 350 mA | 收发同时 |

### 电池续航估算

- 18650 单节容量：2500–3500 mAh（取 3000 mAh）
- 2 节串联 = 3000 mAh @ 7.4V（实际是 6000 mAh @ 3.7V 等效）
- 假设 1% 占空比工作（每 30s 唤醒 1s）：
  - 平均电流：350 mA × 0.03 + 50 mA × 0.97 + 0.005 mA × 0 ≈ 60 mA
  - 理论续航：3000 / 60 ≈ **50 小时**（约 2 天）

> **实际优化方向**：
> 1. 进一步降低占空比（每 60s 唤醒 0.5s）
> 2. 缩短发射持续时间（仅 1ms 码元 × 帧长）
> 3. 优化 OPA549 静态电流
> 4. **目标续航：> 7 天**（项目验收标准）

### 优化策略

- 深度休眠时关闭 OPA549、AD8421 等大功耗模块
- 仅保留 RTC 和必要的 RAM 保持
- 使用 TPS22918 负载开关切断不需要的电源
- 磁环驱动仅在发送瞬间使能

## 6. 与中继的接口协议要点

### 物理层

- 调制方式：BFSK，f0 / f1 由中继下发的握手帧确定
- 波特率：1000 Baud
- 码元时长：1ms / bit
- 帧间间隔：≥ 50ms

### 上行帧类型（井下→中继）

| 帧类型 | 长度 | 说明 |
|--------|------|------|
| 业务数据帧 | 13B | 温度2B + 压力2B + 节点ID + 序号 |
| 告警帧 | 11B | 电量 + 故障码 |
| 应答帧 | 4B | ACK/NACK |

### 下行帧类型（中继→井下）

| 帧类型 | 长度 | 说明 |
|--------|------|------|
| 握手帧 | 8B | 携带 f0 / f1 频点 |
| 命令帧 | 7B | 复位/唤醒/休眠/查询/校时 |
| 应答帧 | 4B | ACK/NACK |
