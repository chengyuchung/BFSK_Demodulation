# 远端上位机设计规格

> 本文档详细定义运行在 PC 上的 QT 上位机应用架构、模块、UI 和算法。
> 上位机是整个系统的"用户窗口"，负责数据可视化、命令下发、时序预测、告警管理等。

## 1. 功能职责

- **实时数据展示**：温压曲线、节点状态、网络拓扑
- **频谱分析**：FFT 实时频谱、瀑布图、信道质量统计
- **时序预测**：基于 LSTM/GRU 的温压预测曲线
- **超限告警**：温度/压力阈值告警，弹窗 + 声音 + 邮件/短信通知
- **历史回放**：SQLite 数据库，按时间段查询、回放
- **报表导出**：CSV / Excel / PDF 格式导出
- **命令下发**：远程控制节点（查询、校时、休眠、唤醒、复位）
- **多节点管理**：同时监控多个井下节点（预留扩展）

## 2. 技术栈选型

| 类别 | 选型 | 理由 |
|------|------|------|
| GUI 框架 | Qt 6.x（Widgets + QML 混合） | 跨平台、生态丰富 |
| 开发语言 | C++ 17 | 性能、与 onnxruntime 集成 |
| 图表库 | **QtCharts** + **QCustomPlot** | 内置 + 高性能自定义 |
| 数据库 | **SQLite 3** | 轻量、嵌入式友好 |
| MQTT 客户端 | **QMqttClient**（Qt 官方） | Qt6 内置 |
| HTTP 客户端 | Qt Network | - |
| 预测推理 | **onnxruntime-cpp** | ONNX 模型推理 |
| 模型训练 | Python + PyTorch → 导出 ONNX | 离线训练 |
| 多线程 | QtConcurrent + QThread | - |
| 日志 | spdlog 或 Qt 自带 | - |
| 打包 | windeployqt / linuxdeploy | 跨平台部署 |

## 6. LSTM 时序预测模型

### 模型设计

```python
# train_model.py - Python 训练脚本（离线运行）
import torch
import torch.nn as nn

class TempPressureLSTM(nn.Module):
    def __init__(self, input_size=4, hidden_size=64, num_layers=2, output_size=2):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers, batch_first=True)
        self.fc = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        # x: (batch, seq_len, input_size)
        # input_size: [温度, 压力, 时间(hour), 时间(day)]
        out, _ = self.lstm(x)
        out = self.fc(out[:, -1, :])  # 取最后时间步
        return out  # [pred_temp, pred_pressure]
```

### 训练数据准备

- 输入序列长度：60（1 小时的历史数据，按分钟采样）
- 输出：未来 10 分钟的温压预测
- 特征：温度、压力、时间特征（小时、星期）
- 数据归一化：MinMax 标准化到 [0, 1]

### 导出 ONNX


## 7. 数据库设计

### Schema

```sql
-- 设备表
CREATE TABLE devices (
    device_id TEXT PRIMARY KEY,
    device_type TEXT,        -- 'downhole' / 'relay' / 'surface'
    location TEXT,
    install_time INTEGER,
    last_seen INTEGER
);

-- 业务数据表
CREATE TABLE telemetry (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT,
    timestamp INTEGER,
    temperature REAL,
    pressure REAL,
    battery INTEGER,
    snr_db REAL,
    ber REAL,
    frame_seq INTEGER
);
CREATE INDEX idx_telemetry_device_time ON telemetry(device_id, timestamp);

-- 告警记录表
CREATE TABLE alarms (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT,
    timestamp INTEGER,
    alarm_type TEXT,    -- 'temp_high' / 'pressure_high' / 'low_battery' / 'link_lost'
    value REAL,
    threshold REAL,
    message TEXT,
    acknowledged INTEGER DEFAULT 0
);

-- 信道质量历史
CREATE TABLE channel_quality (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id TEXT,
    timestamp INTEGER,
    freq_f0 INTEGER,
    freq_f1 INTEGER,
    snr_db REAL,
    ber REAL,
    packet_loss_rate REAL
);
```

## 9. 命令下发协议

### 命令类型

| 命令 | JSON 字段 | 说明 |
|------|----------|------|
| 查询 | `{"cmd": "query"}` | 立即上报一帧数据 |
| 校时 | `{"cmd": "sync_time", "timestamp": 1726723200}` | 同步 RTC |
| 休眠 | `{"cmd": "sleep", "duration_sec": 3600}` | 进入休眠 |
| 唤醒 | `{"cmd": "wakeup"}` | 强制唤醒 |
| 复位 | `{"cmd": "reset"}` | 软件复位 |
| 重选频 | `{"cmd": "reselect_freq"}` | 触发重新扫频 |
| 设阈值 | `{"cmd": "set_threshold", "temp_max": 30.0, "pressure_max": 2.0}` | 远程配置告警阈值 |
